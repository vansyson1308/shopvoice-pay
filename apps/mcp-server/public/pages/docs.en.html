ShopVoice documentation

ShopVoice lets the owner of a small grocery or convenience store run the shop from a conversation: check what is running low, see how sales compare with last week, find out whether a supplier invoice has arrived, and draft and confirm reorders. It works in Claude (web, desktop, mobile, Cowork and Claude Code) and by voice with Alexa+.

Server URL: {{MCP_URL}}
Transport: Streamable HTTP (MCP protocol 2025-11-25). Sign-in: OAuth 2.1, a free ShopVoice account.

Who it is for

ShopVoice is for independent grocery and convenience stores (Vietnamese tạp hóa and similar) that use GroceryClaw to track stock, sales and supplier invoices. It is GroceryClaw's own first-party API. Every tool reads or writes only your shop's records in GroceryClaw.

Connect in Claude

From the directory

Open Customize → Connectors, find ShopVoice and select Connect. A ShopVoice sign-in window opens.

As a custom connector

  1. In Claude, open Customize → Connectors and select Add custom connector.
  2. Name: ShopVoice. URL: {{MCP_URL}}. Leave the advanced OAuth fields empty.
  3. Select Connect. In the ShopVoice window, sign in or create an account, check what the app may do, and select Allow.
  4. In a chat, turn ShopVoice on from + → Connectors and ask, for example, "What's running low in my shop?"

Claude Code

claude mcp add --transport http shopvoice {{MCP_URL}}

Then run /mcp in a session and choose Authenticate to sign in. The ShopVoice plugin (shopvoice-plugin) adds skills for a daily briefing, restock planning, sales insights and supplier invoices, and uses this same server.

Your account and your shop

  • New accounts get a demo shop with sample data, labelled "Demo shop (sample data)": 60 products, 5 suppliers, 90 days of sales and 3 supplier invoices, so you can try every tool right away. The sample data resets once a day, which also clears sample drafts.
  • Real shops: ask your shop owner for a GroceryClaw invite code and enter it on your account page. Your account then switches to the real shop. Connected apps must sign in again so they see the new shop.
  • Choose English (prices in US dollars) or Vietnamese (prices in đồng) at sign-up.

The resource shop://profile has the shop name, currency and timezone. The prompt morning_briefing starts a daily briefing.

How reorders stay safe

  1. create_reorder_draft only writes drafts. It returns a one-time confirmation token that expires after 5 minutes and works only for your shop.
  2. confirm_reorder is marked destructive, so Claude asks for your approval before it runs. Confirming changes the drafts' status in your shop's records; ShopVoice never contacts suppliers and never moves money.
  3. Confirming the same drafts twice has no further effect, and expired drafts cannot be confirmed.

By voice (Alexa+), the host keeps the token out of the model, and only an explicit "yes" confirms.

Permissions

  • shop.read: read stock, sales, suppliers and invoices.
  • shop.write: create and confirm purchase-order drafts. You can untick this on the consent screen and keep read-only access. Claude will ask you to reconnect if you later ask for a reorder.
  • offline_access: stay connected; the access token lasts 1 hour and is refreshed automatically for up to 30 days of inactivity.

See and revoke connected apps, or delete your account, on the account page.

Limits

  • 120 requests per minute per shop; sign-in is rate limited, and an account locks for 15 minutes after 5 wrong passwords.
  • Lists are short by design: up to 50 low-stock items, and up to 10 top movers and invoices per call.
  • Sales are daily totals; dates are in the shop's timezone (Asia/Ho_Chi_Minh by default).

FAQ

Does ShopVoice read my chats?

No. It only receives the tool name and arguments Claude sends, such as a product name or a date range. It never reads your conversation, Claude's memory or your files.

Can it pay a supplier?

No. ShopVoice only records purchase-order drafts and confirmations inside your shop's own records.

Where is my data stored?

On Amazon Web Services in the United States. See the privacy policy.

Something failed

Every error message says what to try next. If it keeps failing, write to {{SUPPORT_EMAIL}} (see support).
