# ShopVoice Pay

A voice-first purchasing agent for independent grocers that pays suppliers through PayPal, only within spending rules the owner sets. Built for the PayPal AI Hackathon 2026.

## Credits

This first commit imports parts of [GroceryClaw](https://github.com/vansyson1308/groceryclaw) (MIT), commit `0fb3af4`, unchanged and at their original paths: the ShopVoice MCP server, the push-to-talk console, shared utilities, Postgres migrations, and the scripts, tests and tools they need. No payment code is included. See [NOTICE](NOTICE).
